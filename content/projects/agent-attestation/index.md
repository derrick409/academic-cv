AI agents increasingly call tools, APIs and other agents on our behalf. Today's identity and trust frameworks assume an agent can always reach a server to check credentials, an assumption that breaks in much of the world.

<!--more-->

This project develops a lightweight attestation protocol that lets agents prove where a tool call came from and verify it locally, so trust holds even on intermittent networks. It targets the resource constrained deployments common across Africa and other emerging regions.

Full working title: *Lightweight Attestation Based Provenance Verification for Autonomous AI Agent Tool Invocation: A Connectivity Resilient Trust Protocol for Resource Constrained AI Deployments.*

**Status:** Ongoing research.
