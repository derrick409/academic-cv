Quantum programs depend on a fast growing ecosystem of open source compilers, SDKs and libraries. The security practices that now protect classical software supply chains have barely reached it.

<!--more-->

QSentry is an open source tool for detecting supply chain risks in quantum software projects, so that researchers and developers can trust the dependencies their circuits are built on. It is designed to fit into the workflows quantum developers already use.

**Status:** In active development.
